# Hello

Weightroom Whiteboard is an application for tracking workouts specifically for strength training.

The technologies used are React, Vite, and Nodejs.

This Codebase contains the frontend. There is a seperate api layer.

# Pushing updates

There are respositories on both Gitlab and Github

The Gitlab repository is actively used, the Github repository is for visibility

There is a dev branch and a main branch on both repositories

# Directions for pushing updates

1. Push to Gitlab dev branch
2. If tests pass, merge on Gitlab into main branch
3. Push to Github dev branch after pushing to Gitlab
4. Merge Github dev branch into Github main branch
